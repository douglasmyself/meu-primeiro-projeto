# 🏫 Sistema de Gestão Escolar (CLI)

Um projeto interativo desenvolvido em **Python** para gerenciamento de turmas, alunos e notas, aplicando conceitos fundamentais da ciência da computação e orientação a objetos.

---

### 🚀 Funcionalidades
- 📝 **Cadastro de Alunos:** Registo de nomes e avaliações parciais.
- 📊 **Cálculo Automático:** Média individual e status acadêmico (Aprovado / Recuperação).
- 📋 **Relatórios:** Listagem completa de alunos e cálculo da média geral da turma.
- 🛡️ **Tratamento de Erros:** Validação de entradas para evitar falhas de execução.

---

### 💻 Conceitos Aplicados
- Programação Orientada a Objetos (Classes e Métodos)
- Manipulação de Estruturas de Dados (`Listas` e `Dicionários`)
- Estruturas de Controle e Repetição (`While`, `If/Else`)
- Tratamento de Exceções (`Try/Except`)

---

### 🔧 Como Executar
Certifique-se de ter o Python 3 instalado e execute no terminal:

```bash
python app.py
